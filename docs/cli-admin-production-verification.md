## 真实 SSH 链路

生产宿主没有 Node。验收通过 SSH 在有内存、CPU 和进程上限的临时容器内运行
打包后的 CLI，使用 Node 24；仅挂载完整 dist、独立凭据目录和本轮文件目录，
没有浏览器、端口转发、入站回调或客户端秘密。

管理员在另一台机器的浏览器核对账号、短码和权限，明确同意
`admin:read admin:write`。终端随后实际取得授权，身份和 scope 回读一致。
凭据目录权限为 `700`，文件为 `600`；验收结束后已服务端撤销并删除文件，
原凭据访问 `/api/oauth/me` 返回 401。

## SSH 日常使用

服务器已安装 `/usr/local/bin/azn`，完整 dist 独立存放于
`/srv/adrian-zephyr-notes/.git/cli/0.2.0/dist`。入口复用预置 Node 24 镜像，
按调用用户保存凭据，限制 256 MiB 内存、384 MiB 含 swap、0.5 CPU 与 64 个进程。
仅挂载当前目录树、只读 CLI 和私有凭据目录；请在文章文件目录调用，绝对文件路径也须位于该树。

```bash
azn --help
azn auth login --server https://zephyrai.site --no-browser
azn articles create --title '文章标题' --description '文章摘要' --file ./article.md --upload-images
azn articles publish ARTICLE_ID
azn auth logout
```

入口已实际运行帮助、无凭据状态检查和 stdin 本地 PNG 预检。
无凭据时返回 `AUTH_REQUIRED` 并退出 1，供 Agent 判断需要登录。
纯本地预检使用虚构凭据和无效示例域名，没有重新申请真实授权或写入生产数据。
真实授权和文章写入流程使用此前记录的独立验收凭据完成，随后已撤销。
